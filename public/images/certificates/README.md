# 证书图片目录

请将您的证书图片放在此目录中。

## 需要的图片文件：

1. **br-cert.jpg** - 香港商业登记证图片
   - 文件路径：`public/images/certificates/br-cert.jpg`
   - 建议尺寸：宽度 800-1200px，保持原始比例
   - 格式：JPG、PNG 或 WebP

## 如何添加图片：

1. 将您的商业登记证图片文件复制到此目录
2. 重命名为 `br-cert.jpg`（或保持原文件名，然后更新 `src/content/company.ts` 中的路径）
3. 刷新浏览器查看效果

## 支持的图片格式：

- JPG / JPEG
- PNG
- WebP

建议使用 JPG 格式以获得更好的压缩率和加载速度。
